# 算法学习笔记

个人算法竞赛的学习仓库：刷题记录、通用板子、比赛赛题和备赛资料。

## 层级

整体分三层，层数不固定：

1. **模块** —— 按用途划分，见下表。
2. **主题 / 场次** —— 模块下按算法主题（如「图论」「动态规划」）或比赛场次分组。
3. **单题 / 单板** —— 具体某道题的代码，或某块板子的源码。

`practice/` 里的主题会按需要再往下嵌套（例如「图论 → 树 → 最近公共祖先」），`competitions/` 则固定是「赛事 → 场次」两层。因此这里只约定各层的职责，不列出具体目录——目录结构会随学习进度调整。

## 模块

| 路径 | 作用 |
| --- | --- |
| `practice/` | 日常刷题。按算法主题组织，主题下存放板子、题目代码和测试数据。 |
| `template/` | 通用板子。`code/` 是可复用的模板源码，`README.md` 是板子清单，`docs/` 存放按日期导出的合订文档。 |
| `competitions/` | 比赛记录。按赛事（ICPC、CCPC、CCF、Codeforces、蓝桥杯等）分目录，每场一个子目录，存放赛时代码、补题和赛题资料。 |
| `docs/` | 长期保留的项目文档：考前提醒、提交规范、参考书。 |
| `tmp/` | 临时草稿，随手写的东西，不保证能跑。 |
| `mo4xie3/` | 默写板子的地方。 |
| `bin/` | 编译产物输出目录，不入库。 |
| `Question.md` | 零散疑问的收集处。 |

## 命名

目录名用「拼音 + 声调数字」表示中文主题，避免同音歧义：

| 目录名 | 含义 |
| --- | --- |
| `tu2lun4` | 图论 |
| `pai2xu4` | 排序 |
| `xian4duan4shu4` | 线段树 |
| `ke3chi2jiu3hua4` | 可持久化 |

文件名沿用评测平台的题号（如 `P3372`、`AcWing102`），方便对回原题。

## 构建

- 编译器 g++，`-std=c++17`（见 `.vscode/tasks.json`）。
- 编译产物统一输出到仓库根目录的 `bin/`，与源码分离；构建产物、测试数据等已在 `.gitignore` 中忽略。
- `template/code/` 下的板子只保留函数体，`#include` 和 `main()` 由调用处补齐。
