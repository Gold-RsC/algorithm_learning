## 由数据范围推算法

- $1 \le n \le 15$: 状态压缩
- $1 \le n \le 500$: O(n^3)
- $1 \le n \le 2000$: O(n^2)
- $1 \le n \le 1e5$: 桶 /  O(n logn)/O(n \sqrt{n})
- 更大 : O(n) / O(log n) / O(\sqrt{n})
